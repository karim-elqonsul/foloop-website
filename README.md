# Foloop website

[View the website](https://karim-elqonsul.github.io/foloop-website/) · [Pricing](https://karim-elqonsul.github.io/foloop-website/pricing.html)

## GitHub Pages

The site is published from the `docs` folder on the `main` branch. Edit the HTML, CSS, JavaScript and assets in `docs` and commit to `main` to publish updates. No build step is required

A responsive bilingual website using the supplied orange and navy identity, with pale blue lighting and marketing structure informed by Hostinger, Media Shield and HighLevel.

## Preview and validation

Run `python3 -m http.server 4173 --directory docs` from this folder, then open http://localhost:4173

Run `node scripts/check-growth.mjs` to validate report calculations, invalid input handling and downloadable HTML output

## Included

- Arabic and English, RTL layouts and a saved language preference
- An interactive hero with CRM, inbox and automation views
- A conversation journey controlled with the mouse, four steps, keyboard slider and play/pause
- A moving rail of colored social logos and an interactive view explaining a connected workspace
- Twenty-two feature scopes, eight business sectors and a searchable library of thirty-six ecosystem logos
- Monthly and annual plan previews, feature comparison and six optional add-on scopes
- A local setup brief including billing, sector, feature interests and add-ons
- A free business self-assessment with conversion and follow-up coverage, recommendations and HTML report download
- Responsive layouts, keyboard controls, reduced motion support and accessible dialogs

## Commercial content

Pricing is clearly labeled as suggested for design review, not a confirmed offer: 399 / 799 / 1,499 SAR monthly and 349 / 699 / 1,299 SAR per month billed annually

Product screens, conversations and metrics are illustrative. Brand logos identify tools for compatibility planning, not confirmed integrations. External accounts, API permissions, channel fees and usage costs can remain necessary. The setup builder and growth check do not submit details, connect accounts, process payments or create an account

The report uses visitor-entered figures from one reporting period. It calculates conversion and follow-up coverage and suggests workflow improvements; it does not audit external analytics or forecast revenue
